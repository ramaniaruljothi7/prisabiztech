# Prisa Biztech Solutions Website

Static production website for Prisa Biztech Solutions.

## Files

- `index.html` - main website page
- `styles.css` - site styling
- `script.js` - navigation, gallery, lightbox, and form behavior
- `assets/` - images, brand files, favicon files, and client logos
- `site.webmanifest` - install/icon metadata for browsers
- `robots.txt` - crawler access file

## Deploy

Deploy the repository root as a static site. No build step is required.

Common static hosting settings:

- Build command: leave empty
- Publish directory: `.`
- Entry file: `index.html`

After deployment, update social sharing URLs or sitemap settings only if the hosting platform requires an absolute public domain.
